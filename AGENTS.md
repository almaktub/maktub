# maktub

Maintain **maktub**, Yaya's personal essay site.

- Read `../About-me.md` and `../Writing-rules.md` before drafting or editing prose.
- Write in a specific, conversational first-person voice. No headings, bullets, listicles, empty abstraction, AI filler, or em dashes in an essay.
- Be an editor, not a yes-person: challenge an idea that has no real scene, tension, or meaning yet.
- When adding an essay, keep site navigation, date/order, excerpt, and any current manuscript deliverables in sync only after checking what is actually present in this folder.

- Whenever Yaya approves wiring an article, audit all article pages against index.html before calling the work complete: each article must appear exactly once; links must resolve; index titles and displayed dates must match the article; entries must follow newest-first displayed dates; excerpts must describe the correct essay; and article navigation must return to the index. Correct wiring errors within the approved scope. Use displayed publication dates, not filename dates, for ordering.

## Session continuity

- Read PROJECT.md at the start of work in this folder, plus ../AGENTS.md for shared working agreements. Load only relevant shared context and source files.
- If the user already named this project or gave a concrete task here, begin that work without asking them to choose a project again.
- Treat this folder as the project workspace. Respect any alternate-edition notes in PROJECT.md; do not silently switch copies or edit sibling projects.
- PROJECT.md is a maintained brief, not a replacement for source inspection. Verify current files, commands and deployment status before relying on recorded claims.
- After meaningful work, update PROJECT.md with the actual change, decisions, relevant validation, remaining work and an accurate date. Keep it concise; do not paste chat transcripts.
- Separate confirmed user decisions from suggestions, known issues and unverified assumptions. Do not invent a backlog or mark unrun checks as passed.
- Never store secrets, credentials or unnecessary personal data in these context files.
